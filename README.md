# GM Companion

**GM Companion** es una aplicación diseñada para facilitar la labor del Director de Juego (GM) en diversas ambientaciones de rol y juegos de mesa. Proporciona herramientas de generación aleatoria, gestión de combates y emulación de decisiones.

## Características Principales

### 🦸 Marvel United
Generador de partidas para el juego de mesa Marvel United:
- **Selección Inteligente**: Elige héroes y villanos evitando repeticiones consecutivas.
- **Memoria de Villanos**: La aplicación recuerda los últimos 5 villanos seleccionados (incluso entre sesiones) para asegurar la variedad.
- **Listas Claras**: Presentación de héroes y villanos en listas con viñetas para una lectura rápida.
- **Generación de Escenas**: Integración con IA para generar un breve texto ambiental sobre el plan del villano.

### ⚔️ The Witcher
Herramientas para el juego de rol de The Witcher:
- **Generador de Encuentros**: Crea enemigos y situaciones de combate rápidamente.
- **Eventos de Vida**: Generación aleatoria de trasfondos y sucesos para personajes.
- **Flujo de Combate**: Ayuda a gestionar la iniciativa y el estado de los encuentros.

### 🤖 BattleTech & Alpha Strike
Utilidades para los aficionados a los mechas:
- **Generador de Lanzas**: Crea unidades equilibradas basadas en el valor de combate (BV).
- **IA de Combate**: Cartas de movimiento y ataque para jugar en solitario o contra una "IA" básica.
- **Soporte Alpha Strike**: Herramientas específicas para la versión rápida del juego.

### 🔮 Mythic GM Emulator
Implementación digital del popular sistema de emulación de GM:
- **Tabla de Destino**: Resuelve preguntas de Sí/No según las probabilidades y el valor de caos.
- **Eventos Aleatorios**: Genera giros inesperados en la trama.

## Mejoras Recientes

- **Navegación Optimizada**: Se ha añadido una flecha de retorno en todas las pantallas secundarias para volver fácilmente al selector principal.
- **Migración a View Binding**: El código se ha actualizado para usar `View Binding`, mejorando la estabilidad y el rendimiento del acceso a la interfaz de usuario.
- **Actualización Tecnológica**: Compatible con **Java 21** y **Gradle 8.5**.

## Requisitos de Desarrollo

- **Android Studio**: Versión Jellyfish o superior recomendada.
- **JDK**: Java 17 o superior (actualmente configurado para Java 21).
- **Gradle**: 8.5.
